# XRR 拟合工作台（WGallop Agent 插件）

X 射线镜面反射率（XRR）拟合工作台：层结构建模、Parratt 仿真、差分进化拟合、GenX 项目导入。

## 快速上手（5 分钟）

装好之后按这个顺序走一遍，就能得到第一条拟合结果。

### 1. 打开插件

侧栏「插件」区点 **XRR 拟合工作台**。首次打开会弹后端授权确认，点允许。

### 2. 导入数据

顶栏 **「导入数据…」** → 选一个 `.txt` / `.dat` 数据文件。

- 左侧出现数据集，显示点数
- 单位自动判断：数值最大值 > 5 判为 `2θ`，否则 `q`
- **单位不对就点数据集右侧的小按钮循环切换** `q → 2θ → θ`

导入后不会自动仿真（避免默认模型误导），需要手动按 F9。

### 3. 建膜系

切到 **「层结构」** 页：

| 位置 | 填什么 |
|---|---|
| 环境 | 通常是 `Air` / 0.0012 |
| 段 N | 一个段 = 一个周期；段头可设重复次数 |
| 层 | 材料（化学式）、密度 g/cm³、厚度 Å、界面宽度 Å |
| 衬底 | 材料、密度、界面宽度 |

操作：点段内「＋ 层」加层，点底部「＋ 段」加周期，点行尾 ✕ 删除。
底部会实时显示展开后的总层数。

### 4. 设仪器参数

切到 **「仪器与拟合」** 页：波长、I₀、本底、分辨率类型与宽度、footprint 类型与束宽/样品长、FOM、最大代数。

### 5. 仿真

按 **F9**（或顶栏「仿真」）。绘图区出现模拟曲线，与数据点对比。

曲线差很远时依次检查：单位是否选对、密度是否填成 g/cm³、段重复次数是否正确。

### 6. 拟合

切到 **「参数」** 页：参数由层结构自动生成，**不需要手写**。

每行做两件事：勾选「拟合」、填「最小/最大」。

然后按 **Ctrl+F**（或顶栏「开始拟合」），页面自动跳到 FOM 收敛图。
拟合完成后参数值回填，误差列显示 `± 数值`。

### 7. 导出

顶栏 **「导出」**：

| 类型 | 内容 |
|---|---|
| 拟合曲线 `.dat` | x / 实测 / 拟合 / 残差（制表符） |
| 拟合曲线 `.csv` | 同上（逗号） |
| 膜层结构参数表 | 层 / 材料 / 厚度 / 界面宽度 / 密度 / bulk / 密度占 bulk % |
| 拟合参数表 | 名称 / 值 / 拟合 / 边界 / 误差 |
| 结果摘要 `.txt` | 仪器、层结构、FOM、参数一览 |

文件默认存到 `C:\Users\<你>\\Documents\XRR\`。

### 8. 保存工程

顶栏 **「保存」** 存成 `.json`；**「打开工程」** 可再打开 `.json` 或 GenX 的 `.hgx`。

打开 `.hgx` 会一次性带出层结构、参数、仪器与数据，适合拿来当模板再微调。

## 功能

- 数据导入：文本两/三列、Bruker RAW、GenX 导出的 `.dat`（自动识别列）
- 横坐标单位：q / 2θ / θ 三种，可一键切换
- 层结构：环境 / 分段（每段可重复 N 次）/ 衬底，材料用化学式（支持 `Ni93V7`、`Ni2O3`）
- 物理内核：Parratt 递推 + Nevot–Croce 粗糙度 + 分辨率卷积 + footprint
- 拟合：差分进化，5 种 FOM，参数误差估计（Jacobian 协方差）
- 仪器参数可拟合：波长、I0、本底、分辨率宽度、束宽、样品长、角度偏移
- 输出：拟合曲线 `.dat`/`.csv`、膜层结构参数表（含密度 g/cm³ 与占 bulk 百分比）
- GenX 项目（`.hgx`）导入：解析脚本、参数表、仪器与数据

## 安装（协作者）

### 1. 克隆仓库

```bash
git clone https://github.com/<账号>/xrr-studio.git
```

### 2. 安装后端依赖

插件后端需要 numpy 与 h5py。WGallop 自带的 Python 没有它们，装到插件目录即可：

```bash
python tools/install_deps.py
```

脚本会自动寻找 WGallop 的随包 Python（`%USERPROFILE%\.wgallop\runtimes\plugin-python\*\python.exe`），
把 `numpy`、`h5py` 装进 `vendor/`。也可以用系统 Python：

```bash
python tools/install_deps.py --python "C:\Path\To\python.exe"
```

### 3. 让 WGallop 识别插件

两种方式，任选：

**方式 A：作为开发仓库（推荐，改代码即生效）**

把克隆下来的目录（根目录含 `plugin.json`）设为 WGallop 的**当前工作区**，
软件会自动识别为插件开发仓库，插件列表里显示 dev 标记。
修改文件保存后约 1.6 秒自动重建页面，不需要反复关开插件。

**方式 B：作为普通插件安装**

设置 → 插件管理 → 导入 → 导入本地文件夹，选择该目录。

### 4. 授权后端

首次打开插件会要求确认 Python 后端授权，点允许。
**改了 `backend/` 下任何 `.py` 后，需要重新打开插件并确认一次**（授权绑定源码指纹）。

| 绘图区 · 数据页 | 数据点 + 模拟曲线，纵轴对数 |

## 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 点按钮完全没反应 | 页面脚本没加载完或旧版本 | 关掉插件标签重开 |
| 仿真/导入报「未连接到宿主后端」 | 后端未授权 | 重新打开插件并在弹窗里允许 |
| 改了 `backend/*.py` 后全部失灵 | 授权绑定源码指纹，改动即失效 | 重新打开插件确认一次 |
| 导入 `.hgx` 报 schema 错误 | 清单里 `import_hgx` 的 `required` 过严 | 更新到最新代码 |
| 曲线与数据差很远 | 单位选错 / 密度填成 atoms/Å³ / 段重复次数不对 | 逐项核对 |
| 拟合参数全跑到边界 | 代数太少（<100）或边界太窄 | 代数加到 200+，放宽 min/max |
| 拟合很慢 | 层数多 + 分辨率卷积，每次评估约 0.15 s | 先把分辨率设为「不卷积」试跑 |
| 导入 GenX `.dat` 强度不对 | 那是导出结果（第 2 列是模拟值） | 插件已自动识别列；若文件无注释头，需手工整理成两列 |

## 目录结构

```
plugin.json          清单（id / 入口 / 后端 / 权限）
index.html           主页面
assets/app.js        界面与交互
assets/app.css       样式（跟随宿主主题令牌）
backend/core.py      物理内核：SLD、Parratt、分辨率、footprint
backend/fit.py       差分进化与误差估计
backend/hgx.py       GenX 项目文件解析
backend/project.py   项目保存/读取、数据导出
backend/server.py    后端入口（MCP over stdio）
data/materials/      元素散射因子（Cromer-Mann f0、NIST f1/f2、原子量）
tools/install_deps.py 依赖安装脚本
```

`vendor/` 不在仓库里：它是平台相关的二进制依赖，由 `tools/install_deps.py` 生成。

## 开发约定

### 改代码后什么时候生效

| 改动位置 | 生效方式 |
|---|---|
| `index.html`、`assets/*.js`、`assets/*.css` | 保存后约 1.6 秒自动重建页面，**不用关开插件** |
| `backend/*.py` | 需要**重新打开插件并确认授权**（授权绑定源码指纹） |
| `plugin.json` | 同上（清单变化也会改变指纹） |

### 提交前自检

1. GitHub Desktop 的 Changes 里只应有你改的那几个文件
2. 不应出现 `vendor/`（`.gitignore` 已排除）
3. 不应出现 `data/materials/*.nff` 的大批变化（除非确实改了元素数据）
4. 提交信息写清楚改了什么，例如 `修正分辨率宽度单位换算`

### 分支建议

```bash
git checkout -b feature/xxx    # 新功能
git checkout -b fix/xxx        # 修 bug
```

做完提 Pull Request，由维护者合并到 `main`。

### 后端接口改动要同步三处

新增或修改页面方法时，以下三处必须一致，否则前端调用会被拒绝或报 schema 错误：

1. `backend/server.py` 的 `_TOOLS` 里注册（`name` / `inputSchema` / `execute`）
2. `plugin.json` 的 `backend.ui_methods`（`read` 或 `host`）
3. `assets/app.js` 里的 `callBackend('方法名', {...})`

参数 Schema 里不要写死 `required`，除非确定所有调用方都传该字段——浏览器拿不到文件路径，只能传内容。

## 物理约定

| 项 | 约定 |
|---|---|
| 层序 | 环境 → 段1 → 段2 … → 衬底（与界面显示一致） |
| 密度 | **g/cm³**（GenX 用 atoms/Å³，导入时自动换算） |
| 粗糙度 | 界面宽度 σ（Å），指该层与**上方层**的界面 |
| 段 | 一个段内所有层构成一个周期，重复 N 次 |
| 分辨率宽度 | 以横坐标单位给出（2θ 或 θ 的度），内部换算到 q |

## 已知限制

- 只做 X 射线镜面反射率，不含中子/磁散射/SXRD/GISAXS
- 单一数据集，无联合拟合
- `vendor/` 为当前平台编译版本，跨平台需重新运行 `install_deps.py`
